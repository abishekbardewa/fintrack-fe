# FinTrack (Frontend)

React + Vite + TypeScript frontend for FinTrack.

## Requirements

- Node.js `>= 20.19.0`
- npm `>= 10`

## Setup

```bash
npm install
```

## Scripts

```bash
npm run dev        # start dev server
npm run build      # production build
```
